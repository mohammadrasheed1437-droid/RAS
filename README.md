# 🏆 Sports League Management System

## 📌 Project Description

The Sports League Management System (SLMS) is a dynamic web application designed to simplify the management of sports leagues.

The system allows administrators to manage teams, fixtures, scores and league information. Users can create an account, login, view fixtures, check standings, view player statistics, book tickets and receive news updates.

The project is developed using only HTML, CSS and JavaScript.

---

## 🎯 Problem Statement

Managing sports leagues manually can be difficult because organizers need to maintain information about teams, players, fixtures, scores, standings and tickets.

This project provides a simple web-based system to organize and manage these activities in one place.

---

## 💡 Objectives

* Manage sports teams.
* Manage match fixtures.
* Update live match scores.
* Display league standings.
* Display player statistics.
* Provide user signup and login.
* Allow users to book tickets.
* Provide sports news and notifications.
* Simplify sports league administration.

## ⚙️ Main Functionalities

### 1. Signup

Users can create a new account.

### 2. Login

Registered users can login using their email and password.

### 3. Admin Login

The administrator can login using the demo admin account.

### 4. Fixture Management

Admin can:

* Add fixtures
* Update scores
* Set match status
* Delete fixtures

### 5. Live Scores

Admin can change a match status to **Live** and update the score.

### 6. League Standings

The system displays:

* Team position
* Matches played
* Wins
* Draws
* Losses
* Points

### 7. Player Statistics

Users can view player:

* Name
* Team
* Matches
* Goals
* Assists

### 8. Ticket Booking

Users can select an upcoming match and book a ticket.

### 9. News and Notifications

Users can read sports news and enable notifications.
